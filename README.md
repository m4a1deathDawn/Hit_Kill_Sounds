# 命中/击杀音效（Hit/Kill Sounds）

[English](README_en.md) | [简体中文](README.md)

**当前版本：v1.5.8**

为《战锤 40,000：暗潮》提供多款经典 FPS 风格的**命中/击杀音效**、**击杀图标与战报 HUD**（BFV / BF1 / CF / Valorant）、**战地 4 风格文字击杀信息与计分**、**自定义音频包（UserAudio）**，以及**哀星号大厅自定义 BGM**。

### 核心亮点

- **18 款内置游戏音源 + 自定义音频包**：普通命中、弱点命中、近战普通/弱点命中、普通击杀、爆头击杀共 6 路音源独立混搭，支持原生命中/击杀音效按需静音。
- **4 套独立击杀图标 HUD**：战地 V 高清队列骷髅（含 Boss 12 齿载具摧毁齿轮、自适应错峰弹出、落位由粗变细冲击波、波浪退场及居中三层战地 V 文字击杀/击中计分信息）、战地 1 双格战报横幅（含中线上下张合与文字同步压缩、全卡斜 45° 左→右扫光、全职业武器/闪击/技能/DoT/同伴精确解析与高价值优先短队列）、穿越火线连杀图标、无畏契约连杀徽章与粒子特效。
- **战地 4 风格文字击杀信息**：独立启用（不依赖连杀开关），还原向下瀑布流、二段终端打字机变身（`[武器/击杀方式]` + 亮红敌名）与无加号累计总分。
- **零代码自定义音频**：放入 WAV / MP3 并编辑文本清单即可替换或扩展命中、击杀与哀星号大厅 BGM，无需修改 Lua。

## 安装与快速开始

1. 确认游戏已安装并启用 **DML**（Darktide Mod Loader）与 **DMF**（Darktide Mod Framework）。
2. 安装并启用两个前置 Mod：**SimpleAudio**（音频播放）与 **SimpleAssets**（图标纹理加载）。
3. 将整个 `Hit_Kill_Sounds` 文件夹放入游戏 `mods/` 目录，与 `SimpleAudio`、`SimpleAssets` 并列。
4. 在 `mods/mod_load_order.txt` 中启用上述 Mod，并确保 `SimpleAudio`、`SimpleAssets` 排在 `Hit_Kill_Sounds` **之前**：
   ```text
   SimpleAudio
   SimpleAssets
   Hit_Kill_Sounds
   ```
5. 启动游戏，打开 Mod 设置中的 **命中/击杀音效**，确认总开关已开启，再按喜好选择音源与 HUD 风格。

> **首次使用建议**：先保留默认 BF1 音源验证命中与击杀声音正常。**战地 4 文字击杀信息**与**哀星号大厅 BGM**默认关闭，按需开启即可。

## 击杀图标与战报 HUD

### 战地 V（BFV）击杀图标与文字击杀信息

还原《战地 V》横向推进式击杀图标队列与居中三层文字计分反馈，内置 `512×512` 无黑边 Lanczos-3 高清贴图（V 型裂口普通骷髅、闪电裂纹爆头骷髅，以及 Boss / 怪物 / 队长专属的 12 齿载具摧毁齿轮）。

- **高冲击力动效与自适应队列**：10 个主槽位 + 8 个离场过渡槽位 + 4 个独立脱钩冲击波槽位，内置自适应多杀错峰弹出队列（首杀 `0ms` 即时响应，同帧群杀按 `0.095s → 0.035s` 动态节拍连珠弹出，满载优先保护 `Boss > 爆头 > 普通`）；采用高倍率半透明空降压入（`0.15 → 1.0` 缩放耦合透明度 + 峰值微停）、爆头（`1.12x`）与 Boss（`1.16x` + `45°` 旋转定格）二段微过冲回弹、**落位触发的单环由粗变细平滑冲击波**（粗细双贴图外径锁定 + Alpha 守恒交叉溶解，扩散至 `4.15x`，槽位溢出或续行时由独立冲击波池原地播完），以及阶梯波浪式顺序退场、退场期新杀无缝衔接与 `54%` 最大安全行宽动态挤压。
- **战地 V 居中三层文字击杀信息（默认开启，可独立开关）**：位置、透明度、显示时长及筛选规则自动跟随 BFV 击杀图标并带屏幕边缘防裁切保护，采用战地 V 原版纯净白色 + 阴影样式：
  1. **击杀主信息行**：展示 `敌人名 [击杀方式] +得分`（复用全职业武器/闪击/技能/DoT/同伴精确解析；普通 `+100`、精英 `+200`、专家 `+250`、Boss `+500`），支持尸潮自适应快切队列。
  2. **累计总分大数字**：千分位格式化与平滑滚动递增，全行清空后柔和淡出归零。
  3. **额外奖励词条栈（最多 3 行）**：包含**爆头击杀（`+50`）**、独立 `5.0s` 窗口**连杀奖励**（双杀/三杀/四杀/五杀/多重击杀），以及可选的**击中敌人加分**（按单次伤害占目标最大生命值百分比折算，涵盖非致命命中与致死一击，内置单位级上限追踪与溢出伤害剔除确保单个敌人累计精确为 `+100`，并配小数累加器避免高血量 Boss 轻伤丢分；命中期间置顶滚动 `命中敌人 +N`、停火 `1.5s` 后平滑落栈淡出，且与命中音效开关完全解耦）。
- **可调参数**：透明度、普通/爆头/Boss 三组自定义 RGB、Boss 齿轮开关、水平/垂直位置、图标缩放（`0.5–2.0x`）、显示时长（`1.0–3.0s`），以及文字击杀信息开关、击中敌人加分开关与文字大小缩放（`50%–150%`）。

### 战地 1（BF1）击杀图标与双格战报横幅

还原《战地 1》经典的屏幕中下方双格战报横幅，内置 3 张经 HSV 亮度归一化去色与预乘 Alpha 超采样生成的 `256×256` 纯白高清贴图（普通骷髅交叉骨、爆头裂颅骷髅、Boss 8 齿工业旋转齿轮），支持任意 RGB 无偏暗染色。

- **双格战报与全职业击杀方式解析**：左侧正方形暗底图标框（含左缘状态色条）无缝贴合右侧自适应宽度信息框，展示本地化敌名、击杀方式与右侧大号数值（默认 BF1 经典击杀分值，可切换为目标最大生命值、致死伤害或隐藏）。击杀方式按 `damage_profile` 精确区分常规近战/远程武器、武器专属爆炸（榴弹炮/爆弹枪/等离子/法杖/动力锤等）、全职业闪击手雷与战斗技能（直接读取游戏原生 `ArchetypeTalents` 译名）、各类 DoT（流血/燃烧/灵火/毒素/电击/腐化）、环境油桶爆炸以及赛博猎犬/伺服颅骨同伴。
- **原版风味动效与割草友好队列**：还原《战地 1》标志性的**水平中线上下纵向展开**（入场 `0.13s` `EaseOutQuart`）与**上下向中线纵向压缩收拢**（退场 `0.20s`，文字字号与行距随卡片高度同步压缩收敛、不溢出黑框，退场中途连杀可从当前开合度平滑重张）；张开定帧及连杀刷新后触发**整张卡片斜 45° 从左向右统一扫光**（解析裁剪严格锁在卡片边界内、动态宽横幅恒定 45° 角，并与 3 套轮廓遮罩扫光图集像素共线同步、纯白/金色/自定义颜色均具清晰金属光泽，`icon_only` 透明底时自动仅保留图标轮廓扫光）；搭配爆头二段重击闪白光晕、Boss 8 齿齿轮纯垂直展开后 `45°` 旋转定格与 `1.35x` 延长驻留；内置容量 4 的高价值优先短队列（`Boss > 专家 > 精英 > 爆头 > 普通`），同帧低阶杂兵自动合并显示 `xN` 角标，并支持高优紧急抢占（`0.08s`）与 Boss 防打断保护（`0.65s`）。
- **可调参数**：完整战报横幅 / 仅图标框双模式、敌名配色（经典 BF1 红 / 按敌方阶层）、Boss 齿轮开关、底框不透明度、普通/爆头/Boss 三组 RGB，以及与 BFV 对齐的透明度、水平/垂直位置、大小（`0.5–2.0x`）与显示时长（`1.0–4.5s`）。

### 战地 4（BF4）风格文字击杀信息与计分

在 **战地 4 风格文字击杀信息** 中直接开启即可，**不依赖连杀机制、音效或图标开关**。还原《战地 4》经典的无边框向下瀑布流击杀提示、两段终端打字机变身与右侧冷白大号累计总分。

- **向下瀑布流（默认）**：最新击杀居于锚点顶部，同批奖励行（爆头奖励、多杀奖励）顺次向下展开，旧批次平滑下推并在第 `3.5–5.8` 行自然渐隐；闲置到期后自底向上错峰清屏，也可在设置中切回「从下往上推入」。
- **原版两段打字机变身（默认）**：击杀主行先以打字机节奏确认事件名（如 `击杀专家 250`，驻留 `0.60s`），随后在 `0.08s` 内快速退格擦除，紧接着从左向右连续逐字敲出冷霜白 `[击杀武器/方式]` 与战地 4 亮红 `敌人名称`（约 `0.22s`，右侧分值全程稳固不闪动）。支持切换为同样带打字效果的「直接显示武器与敌名」或「仅显示事件名」，武器与敌名均可独立开关，并与 BF1 共享全职业闪击/技能/武器爆炸/DoT/同伴精确识别。
- **原版无加号分值与可选多杀奖励**：单行分值与累计总分均不带 `+` 号（普通 100、精英 200、专家 250、Boss 500、爆头奖励 50）。开启通用连杀机制时会额外追加多杀奖励行；关闭连杀机制时照常显示击杀、武器/敌名与爆头奖励。累计总分支持冷青微光双层渲染、二段弹性缩放（`1.0 → 1.24 → 1.0`）、自动避让长分值并与末行同步退场。
- **说明**：HUD 分值仅作视觉展示，不影响游戏正式结算与奖励；若同时开启游戏原生击杀提示，可能出现重复信息。

### 穿越火线（CF）连杀播报与图标

在 **通用设置** 中开启 **启用独立连杀计数器**；在 **击杀音效设置** 中将 **连杀音效样式** 设为 `CF`（确认击杀音效已开启），并在 **CF 击杀音色** 中选择男声或女声；如需 CF 图标，在 **击杀图标设置** 中将图标风格设为 `CF`。音效与图标可自由混搭（如 CF 播报 + BFV/BF1 图标）。

- **男声 / 女声规则**：男声第 1–9 杀顺序播报，第 10 杀起复用第 9 段；女声第 1–8 杀顺序播报，第 9 杀起复用普通首杀音效。切换音色后下一次击杀直接延续当前连杀序号。
- **爆头与 Boss**：首杀弱点击杀播放所选音色的专用爆头音效（文件缺失或启用「爆头使用普通音效」时回退为普通首杀音）；Boss 击杀播放专属 Boss 音效且不打断普通连杀序号。
- **图标与上限**：逐级显示 1–6 杀图标（首杀爆头支持黄金爆头图标），超过最高档位后沿用最高档；连杀计数上限默认 13（可调 10–30），重置窗口默认 2.0 秒（可调 1.0–3.0 秒）。CF 连杀音效激活时优先替代普通击杀音源（包括自定义音频包）。

### 无畏契约（Valorant）连杀音效与 HUD

在 **通用设置** 中开启 **启用独立连杀计数器**；在 **击杀音效设置** 中将 **连杀音效样式** 设为 `Valorant`，在 **击杀图标设置** 中将图标风格设为 `Valorant`（音效与图标可单独启用）。

- **音频与 HUD**：内置第 1–5 杀音效、首杀出现音、连杀过渡音与独立可开关的 UI 层伴随音效；超过第 5 杀后复用第 5 杀视听资源，计数器继续按通用 `cf_killstreak_max` 上限累计，Boss 击杀正常计入。
- **视觉定制**：提供 **经典骷髅** 与 **标准 X 翼** 两种徽章样式、1–5 杀切线弧段、爆头专属粒子特效开关，以及透明度、大小与水平/垂直位置调节。

> **独立计数说明**：BF4 多杀、CF 音效、CF 图标、Valorant 音效与 Valorant 图标各自维护独立的计数与目标筛选，互不强制同步。

### 方法一：直接替换默认 WAV（推荐新手）

1. **完全退出游戏**，备份原有 `Normal.wav` / `Headshot.wav`。
2. 用音频软件将个人音效真正导出为 **WAV**（推荐 PCM 16-bit、48 kHz、单声道或立体声；直接改 MP3 后缀无效）。
3. 覆盖 `UserAudio/Hit/` 或 `UserAudio/Kill/` 下对应文件，保持原文件名与位置不变（默认清单已填好）。
4. 启动游戏，在 6 个音源下拉框中按需选择 **自定义音频包**，确认对应开关与音量正常。

> 建议在 Windows 资源管理器中开启「查看 → 显示 → 文件扩展名」，避免误保存为 `Normal.wav.wav` 或 `playlist.txt.txt`。

### 方法二：通过清单添加多个随机音效

将 WAV 放入 `UserAudio` 后，用记事本编辑 `UserAudio/Hit/playlist.txt` 或 `UserAudio/Kill/playlist.txt`，每行格式为 `类别|相对 UserAudio 的路径`（类别仅认 `normal` 或 `headshot`，不按文件夹名猜测）：

```text
# 命中清单示例：UserAudio/Hit/playlist.txt
normal|Hit/Normal.wav
normal|Hit/normal/metal_01.wav
headshot|Hit/Headshot.wav
headshot|Hit/headshot/headshot_soft.wav
```

```text
# 击杀清单示例：UserAudio/Kill/playlist.txt
normal|Kill/Normal.wav
normal|Kill/normal/kill_01.wav
headshot|Kill/Headshot.wav
headshot|Kill/headshot/headshot_01.wav
```

| 常见操作 | 做法 |
| --- | --- |
| 新增音效 | 放入真实 WAV，在清单末尾添加 `normal\|...` 或 `headshot\|...` |
| 暂时停用 | 在整行最前加 `#` 注释（如 `# normal\|Hit/Normal.wav`） |
| 彻底删除 | 先删除或注释清单行，再删除音频文件 |

### 清单规则与安全回退

- 清单须保存为 **UTF-8 纯文本**（允许 BOM），忽略空行与整行 `#` 注释，不支持行尾注释，单文件上限 64 KiB。
- 路径统一使用 `/` 且不加引号；仅接受 `UserAudio` 内相对路径，拒绝绝对路径、盘符、`..`、通配符与符号链接。
- 每个 SFX 类别最多加载前 **20 条**有效路径，按大小写不敏感去重（重复条目不增加权重）。
- **回退链**：Custom 弱点/爆头池为空 → 同类 Custom 普通池 → 内置 BFV 池（命中与击杀池永不混用；Custom 回退不会额外叠加 BFV 专属爆头尾音）。
- 修改音频或清单后须**完全退出并重启游戏**（清单仅在初始化时读取并缓存）。

## 哀星号大厅 BGM

在 **哀星号自定义 BGM** 中开启开关即可（默认关闭），音量范围 0–100 且调节实时生效不重播，同时受游戏主音量与音乐音量影响。BGM **仅在普通哀星号大厅（`hub`）播放**，不会在任务、主菜单、灵能室或序章大厅播放。

- **默认曲库**：`UserAudio/BGM/tracks.txt` 默认仅含注释，因此沿用内置的 `audio/BGM/Lobby_BGM1.mp3` 至 `Lobby_BGM6.mp3` 随机循环。
- **替换为自定义 MP3**：
  1. 完全退出游戏，将真正的 MP3 文件放入 `UserAudio/BGM/`。
  2. 编辑 `UserAudio/BGM/tracks.txt`，每行写一条相对 `UserAudio` 的路径（无需加 `normal|`/`headshot|` 标签）：
     ```text
     # 相对 UserAudio 的路径
     BGM/My_Lobby_Track.mp3
     BGM/Another_Track.mp3
     ```
  3. 保存为 UTF-8 并重启游戏，打开大厅 BGM 开关即可（无需把命中/击杀来源改为 Custom）。最多加载 20 条，随机切歌并尽量避免连续重复。

| 清单与运行情况 | 实际行为 |
| --- | --- |
| 至少有 1 条有效自定义 MP3 | 优先使用 UserAudio 清单，不与内置六首混播 |
| 清单不存在、为空或全无效 | 自动沿用内置六首大厅 BGM |
| 单首自定义曲目播放失败 | 自动尝试清单中其余有效曲目 |
| 全部自定义曲目失败或环境不可用 | 自动恢复官方大厅音乐，绝不永久静音 |

离开大厅、进入任务、关闭 BGM / 总开关或卸载 Mod 时，会自动淡出停止自定义 BGM 并安全恢复官方音乐。想切回内置六首，清空或注释 `tracks.txt` 后重启游戏即可。

## 常见问题与更新保留

| 常见问题 | 排查建议 |
| --- | --- |
| 没有命中或击杀声音 | 检查总开关、对应音效开关、音量、目标筛选、DoT/同伴/近战开关，以及 `SimpleAudio` 加载顺序 |
| 选了 Custom 却仍是内置音 | 清单路径/类别或真实文件格式无效导致回退至 BFV；检查日志警告与扩展名 |
| 自定义击杀音被 CF/Valorant 替代 | **连杀音效样式**正在生效；切回「关闭」后再测试普通击杀音源 |
| 换了音频或改了清单没生效 | 必须**完全退出并重启游戏**；检查是否保存为 UTF-8、是否出现 `.wav.wav` |
| 击杀图标不显示 | 检查 `SimpleAssets` 加载顺序、图标总开关与图标目标筛选 |
| CF / Valorant 连杀不生效 | 先在「通用设置」启用独立连杀计数器，再检查连杀音效样式 / 图标风格与各自目标筛选 |
| BF4 文字击杀信息不显示 | 检查总开关、BF4 文字信息开关与 BF4 目标筛选（**无需开启连杀机制**，仅多杀奖励行依赖连杀） |
| 哀星号 BGM 仍是内置六首或恢复官方音乐 | 确认在普通 `hub` 大厅、`tracks.txt` 含有效 MP3 且 `SimpleAudio` 正常；播放异常时会主动恢复官方音乐 |

> **更新 Mod 前请先备份个人音频**：完全退出游戏，将整个 `UserAudio/` 复制到游戏目录外的安全位置；更新后再拷贝恢复，切勿将个人音频放入 `scripts/` 目录。
