# 命中/击杀音效（Hit/Kill Sounds）

[English](README_en.md) | [简体中文](README.md)

为《战锤 40,000：暗潮》添加多款游戏风格的命中音效、击杀音效和击杀图标，还可启用 CF 与 Valorant 连杀反馈、战地 4 风格文字计分，以及哀星号大厅 BGM。

**当前版本：v1.5.6**

## 安装与快速开始

1. 确认游戏已安装并启用 DML（Mod 加载器）和 DMF（Mod 框架）。
2. 安装并启用前置 Mod：**SimpleAudio** 用于播放音频，**SimpleAssets** 用于加载图标。
3. 将整个 Hit_Kill_Sounds 文件夹放入游戏的 mods 目录，与 SimpleAudio、SimpleAssets 并列。
4. 在 mods/mod_load_order.txt 中启用这些 Mod，并将 SimpleAudio、SimpleAssets 放在 Hit_Kill_Sounds 之前。
5. 启动游戏，打开 Mod 设置中的“命中/击杀音效”，确认总开关已开启，再选择喜欢的音源和图标风格。

首次使用可以保留默认 BF1 音源，先确认命中、击杀音效正常。大厅 BGM 和战地 4 文字击杀信息均默认关闭，需要时再开启。

## 功能与常用设置

| 想调整的内容 | 在哪里设置 | 说明 |
| --- | --- | --- |
| 普通命中、弱点命中 | 命中音效设置 | 两种音源可分别选择，共用命中音量 |
| 近战普通、弱点命中 | 命中音效设置 | 先开启近战命中，再选择对应的近战音源 |
| 普通击杀、爆头击杀 | 击杀音效设置 | 可分别选择音源，并调整对应音量 |
| 近战击杀音效 | 击杀音效设置 | 独立开关，可关闭近战击杀声音而保留图标 |
| DoT、同伴、目标筛选 | 对应音效或图标设置 | 持续伤害、同伴反馈和生效目标分别控制 |
| 游戏原有命中、击杀声音 | 命中或击杀音效设置 | 可选择保留或关闭游戏原声 |
| BFV、CF、Valorant 击杀图标 | 击杀图标设置 | 调整风格、大小、透明度和位置等 |
| CF 连杀播报与音色 | 通用设置、击杀音效设置 | 启用独立连杀计数器和 CF 击杀音效，再选择男声或女声 |
| Valorant 击杀音效与 HUD | 通用设置、击杀音效设置、击杀图标设置 | 启用 Valorant 音效或图标样式，并单独调整 UI 伴随音、徽章、粒子和位置 |
| BF4 文字击杀信息 | 战地 4 风格文字击杀信息 | 先启用通用连杀机制，再开启文字信息 |

命中音效、击杀音效和击杀图标可以独立开关。普通、弱点和近战命中仍共用一个命中冷却；选择 Custom 不会绕过目标、DoT、同伴、近战或音量设置。

### BFV 击杀图标

BFV 风格使用队列显示 `512×512` 高清战地 5 骷髅击杀图标（普通 V 型裂口骷髅与同源闪电裂纹爆头骷髅），新击杀会推动已有图标移动。当前使用 10 个主槽位和最多 2 个离场过渡槽位，支持普通重砸入场、爆头二段微弹性重击（微放大 4%）与暖白高光闪白、内置粗环爆发 + 细环外扩的双层动态变细爆头冲击波，以及退场向中心微收拢淡出动画。

可调整图标大小、透明度、普通/爆头颜色、水平/垂直位置和显示时长。尺寸范围为 0.5–2.0 倍，显示时长为 1.0–3.0 秒。

### CF 连杀音效与图标

在「通用设置」中打开「启用独立连杀计数器」，然后在「击杀音效设置」中打开「启用击杀音效」和「启用 CF 击杀音效（需启用连杀机制）」。在下方的「CF 击杀音色」中选择男声或女声。默认使用男声，旧配置升级后也默认使用男声。切换音色后，下一次符合条件的击杀会使用新音色并延续当前连杀序号。

- **男声**：第 1 至第 9 杀依次播放对应音效，同一连杀内第 10 杀起继续播放第 9 段。
- **女声**：第 1 至第 8 杀依次播放对应音效，同一连杀内第 9 杀起复用普通首杀音效。
- **爆头**：首杀命中弱点时播放所选音色的专用音效。专用文件缺失或开启「爆头击杀使用爆头来源游戏的普通音效」时，播放该音色的普通首杀音效。后续爆头按当次连杀序号选音。
- **Boss**：使用当前音色的 Boss 专用音效，普通连杀序号在 Boss 击杀前后连续。

CF 音效和 CF 图标可以分开启用，例如搭配“CF 播报 + BFV 图标”，或“普通击杀音效 + CF 图标”。

- 图标逐级显示，超过现有图标档位后沿用最高档；首杀爆头可显示黄金爆头图标。
- 连杀计数上限默认 13，可设为 10–30。计数达到上限后，下一次击杀从第 1 杀开始。重置时间默认 2.0 秒，可设为 1.0–3.0 秒。
- CF 连杀音效生效时，沿用原有优先规则，替代该次普通击杀来源音效；选择 Custom 不会覆盖这一规则。

### Valorant 连杀音效与 HUD

在「通用设置」中打开「启用独立连杀计数器」。在「击杀音效设置」中将连杀音效样式设为 Valorant，并确认击杀音效已启用；在「击杀图标设置」中将图标样式设为 Valorant，并确认击杀图标已启用。音效和图标可以分别开启。

- 提供第 1 至第 5 杀的 Valorant 击杀音效和 HUD 图标资源。音效还包括首杀出现音、连杀过渡音和独立的 UI 层伴随音效。
- Valorant 音效计数器与图标计数器彼此独立，分别使用自己的目标筛选，并共同使用通用的 `cf_killstreak_max` 连杀上限。达到上限后，下一次符合条件的击杀从第 1 杀重新开始。
- 超过第 5 杀后，音效和图标沿用第 5 杀资源，计数器仍按通用上限继续累计。Boss 击杀会正常计入对应的 Valorant 音效或图标计数器。
- 图标支持经典骷髅和标准 X 翼两种徽章样式，可独立控制粒子特效、透明度、大小、水平位置和垂直位置。爆头徽标已调整到更接近骷髅头上部的位置。
- 1–5 杀弧段沿圆环切线方向排列，爆头时可显示对应的粒子和徽章效果。

BF4 文字、CF 音效、CF 图标、Valorant 音效和 Valorant 图标分别维护自己的计数与目标筛选。它们的计数可以不同，不需要强行同步。

### BF4 文字击杀信息与计分

在“通用设置”中启用连杀机制，再打开“战地 4 风格文字击杀信息”。该功能显示无边框的击杀文字、奖励分值和累计总分，不依赖音效或图标开关。

- 普通击杀 100 分，精英击杀 200 分，专家击杀 250 分，Boss 击杀 500 分；爆头另加 50 分，并支持多杀奖励。
- 例如，爆头击杀专家会显示专家击杀和爆头奖励，基础分与爆头奖励合计 300 分。
- 可调整目标、显示时长、位置和文字大小；累计总分在信息列旁单独显示。
- 这里的分值用于本 Mod 的 HUD 展示，不会改变游戏的正式结算或奖励。
- 关闭文字信息或连杀机制会清空当前显示。若同时开启游戏原生击杀信息，可能看到重复提示。

## 自定义命中与击杀音效（UserAudio）

**不用修改 Lua 文件。** 新手可以直接替换默认 WAV；需要多种声音时，再编辑播放清单。下面所有路径均相对 Hit_Kill_Sounds 文件夹。

### 文件放在哪里

~~~text
UserAudio/
├─ README_自定义音频.txt      中文纯文本教程
├─ README_Custom_Audio.txt  英文纯文本教程
├─ BGM/
│  └─ tracks.txt            BGM 清单，默认只有注释
├─ Hit/
│  ├─ Normal.wav           普通命中默认文件
│  ├─ Headshot.wav         弱点命中默认文件
│  ├─ normal/              可放新增普通命中
│  ├─ headshot/            可放新增弱点命中
│  └─ playlist.txt         命中清单
└─ Kill/
   ├─ Normal.wav           普通击杀默认文件
   ├─ Headshot.wav         爆头击杀默认文件
   ├─ normal/              可放新增普通击杀
   ├─ headshot/            可放新增爆头击杀
   └─ playlist.txt         击杀清单
~~~

四个默认 WAV 直接复制自本 Mod 已有的 BFV 音效，用户可替换这些副本。UserAudio 不附带 BGM 占位文件，原有 audio 目录中的资源保留。

### 方法一：直接替换默认 WAV

1. 完全退出游戏，将要替换的默认文件另存到个人安全位置。
2. 用音频编辑软件把自己的音效导出为真正的 WAV。
3. 覆盖 Hit 或 Kill 中对应的 Normal.wav / Headshot.wav，保持文件名和位置不变。默认 SFX 清单已填好，无需编辑。
4. 启动游戏，在相应来源下拉框中选择“自定义音频包 / Custom Audio Pack”。普通命中、弱点命中、普通近战命中、弱点近战命中、普通击杀、爆头击杀共六项，可以分别选择。
5. 确认总开关、对应音效开关和音量正常；近战命中还需打开近战开关。

**格式说明：** SFX 第一阶段只支持 WAV，建议导出为 PCM 16 位、48 kHz、单声道或立体声。将 MP3 改名为 .wav 不等于转换格式；不同 WAV 编码的兼容性仍以实际播放为准。

在 Windows 资源管理器中打开“查看 → 显示 → 文件扩展名”，避免误存成 Normal.wav.wav 或 playlist.txt.txt。

### 方法二：通过清单添加多个音效

把音频放入 UserAudio，再用记事本编辑对应的 playlist.txt。路径从 UserAudio 根目录开始写，前面必须带 normal 或 headshot 标签；文件夹名称不决定分类。

命中清单 UserAudio/Hit/playlist.txt：

~~~text
# 类别|相对 UserAudio 的路径
normal|Hit/Normal.wav
normal|Hit/normal/metal_01.wav
headshot|Hit/Headshot.wav
headshot|Hit/headshot/headshot_soft.wav
~~~

击杀清单 UserAudio/Kill/playlist.txt：

~~~text
normal|Kill/Normal.wav
normal|Kill/normal/kill_01.wav
headshot|Kill/Headshot.wav
headshot|Kill/headshot/headshot_01.wav
~~~

额外文件名只是示例，先放入实际 WAV，再添加清单行。同一类别内有多条有效音频时，每次随机选择一条。

| 想做什么 | 操作方法 |
| --- | --- |
| 新增音效 | 放入 WAV，在清单末尾新增对应类别和路径 |
| 替换某条音效 | 修改该行的文件路径，或覆盖同名文件 |
| 暂时停用 | 在整行最前加 #，例如 # normal\|Hit/Normal.wav |
| 移出播放列表 | 删除对应清单行，音频文件可保留 |
| 彻底删除 | 先移除或注释清单行，再自行删除音频文件 |
| 恢复默认音效 | 恢复默认 WAV，并保留相应的默认清单行 |

### 清单规则与回退

- 保存为 UTF-8 纯文本，允许 BOM；空行、首尾空白和以 # 开头的整行注释会被忽略，不支持行尾注释。
- 路径统一写 /，不要加引号；只接受 UserAudio 内相对路径，拒绝绝对路径、盘符、网络路径、..、通配符和可执行内容。
- 不通过符号链接或目录联接引用外部文件。空格和 UTF-8 文件名可写入清单；遇到读取问题时先尝试简单英文文件名。
- 每个 SFX 类别最多加载前 20 条有效路径；同一类别内重复路径按大小写不敏感规则去重，不增加概率。同一个文件可显式列入 normal 和 headshot 两类。
- 清单最多 64 KiB。缺失文件、错误路径或不支持的格式会跳过并限频警告；超大清单会忽略并回退。
- Custom 弱点/爆头池为空 → 使用同类 Custom normal 池；仍为空 → 使用对应的内置 BFV 池。命中与击杀池不混用。
- “爆头使用普通音效”仍使用所选爆头来源的 normal 池。BFV 的专属爆头叠加尾音只在明确选择 BFV 时触发，Custom 回退也不会自动叠加。

修改文件或清单后，**完全退出并重启游戏**。清单在初始化时读取并缓存，游戏中的命中、击杀和切歌不会重新读取清单或扫描用户目录。

## 哀星号大厅 BGM

在“哀星号自定义 BGM”中打开大厅 BGM 开关即可使用，默认关闭。音量范围为 0–100，播放中调节不会重播当前曲目，同时受游戏主音量和音乐音量影响。

BGM 只在普通哀星号大厅（hub）播放，不在任务、主菜单、训练场、射击场或 prologue_hub 播放。

### 默认播放什么

UserAudio/BGM/tracks.txt 默认只有注释，且不附带 Lobby.mp3，因此默认沿用以下六个文件：

~~~text
audio/BGM/Lobby_BGM1.mp3
audio/BGM/Lobby_BGM2.mp3
audio/BGM/Lobby_BGM3.mp3
audio/BGM/Lobby_BGM4.mp3
audio/BGM/Lobby_BGM5.mp3
audio/BGM/Lobby_BGM6.mp3
~~~

### 换成自己的 BGM

1. 完全退出游戏，准备真正的 MP3 文件，放入 UserAudio/BGM。
2. 用记事本打开 UserAudio/BGM/tracks.txt，每行写一条相对 UserAudio 的路径，不加 normal/headshot 标签：

~~~text
# 相对 UserAudio 的路径；下面文件需要自行添加
BGM/My_Lobby_Track.mp3
BGM/Another_Track.mp3
~~~

3. 保存为 UTF-8，重新启动游戏并打开大厅 BGM 开关。不需要在命中或击杀来源中选择 Custom。

BGM 最多加载 20 条有效路径，随机选曲，并尽量避免连续重复。仅改文件后缀不能将其他格式转换为 MP3。

### 播放优先级与失败处理

| 清单情况 | 播放行为 |
| --- | --- |
| 至少有一条有效 MP3 | 优先使用 UserAudio 清单，不与旧六首混合 |
| 清单不存在、为空或全部无效 | 使用旧六槽位 |
| 某首有效自定义曲目启动失败 | 尝试清单内其他尚未失败的曲目 |
| 所有自定义曲目均启动失败 | 恢复官方大厅音乐，不再切回旧六首 |
| SimpleAudio 或安全音乐控制不可用 | 保留或恢复官方音乐 |

自定义曲目获得有效播放实例后，Mod 才会尝试抑制官方大厅音乐。离开大厅、进入任务、关闭 BGM 或总开关、停用和卸载 Mod 时，会停止自己的 BGM 并恢复官方音乐。

想恢复旧六首，只需把 tracks.txt 中全部曲目行注释或删除，再完全重启游戏。

## 常见问题与更新保留

| 问题 | 先检查这些地方 |
| --- | --- |
| 没有命中/击杀声音 | 总开关、对应音效开关、音量、目标筛选、DoT/同伴/近战设置，以及 SimpleAudio 是否启用 |
| 选择 Custom 后仍听到内置音 | 清单或音频可能无效，已回退 BFV；检查类别、路径、真实文件格式和 Mod 警告 |
| 自定义击杀声音被 CF 播报替代 | CF 连杀音效正在生效；关闭 CF 连杀音效后再测试普通击杀来源 |
| 修改音频或清单后没变化 | 完全退出并重启游戏；检查扩展名是否重复、清单是否保存为 UTF-8 |
| 图标不显示 | 检查 SimpleAssets、图标开关和图标目标筛选 |
| BF4 文字或 CF 连杀不生效 | 先启用通用连杀机制，再检查对应功能开关及各自目标筛选 |
| BGM 仍是旧六首 | 默认如此；UserAudio 清单需要至少一条有效 MP3 才会优先播放 |
| BGM 变回官方音乐 | 检查大厅状态、SimpleAudio 和文件；曲目或安全控制失败时会主动恢复官方音乐 |
